## 這是什麼

Why Ledger 是 **人生主權層（Life Agency Layer）** 的第一個楔子產品：

| 你做什麼 | 系統保證什麼 |
|----------|----------------|
| **收** 材料（筆記、連結、截圖…） | 資料在你可控域 |
| **編** 成「主張／依據／不確定／到期」 | 重要輸出可檢查 |
| **決** 寫下決定與重審日 | 計入有依據的主權決策 |
| **帶** 一鍵匯出 | 換裝置、換模型，脈絡還在 |

**不做：** 成癮動態牆、黑箱人生代理、鎖死匯出的成長手法。

## 原則（不可談判）

1. **Evidence before answer** — 先依據與不確定性，後建議  
2. **Files over vibes** — 持久狀態是可讀結構，不是聊天泡泡  
3. **Degrade gracefully** — 無網、無 LLM，核心路徑仍可用  
4. **Agency defaults** — 預設保護注意力與隱私  
5. **No dark growth** — 不以時長／成癮當成功  
6. **Reversibility** — 自動化可還原、可審計
